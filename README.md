# MicrobiomeNETWORKS_IBD

This repository contains the Python scripts associated with the analytical workflow developed for the study of microbiome
gene networks in inflammatory bowel disease.

The project is based on the integration of microbiome and host transcriptomic data to examine how host microbe association 
patterns are organized across Crohn’s disease, ulcerative colitis, and non IBD conditions. The scripts included here cover
different parts of the workflow and are being organized to provide a clear and traceable record of the computational analyses
performed in the project.

At present, this repository serves as a general code base for the project.
